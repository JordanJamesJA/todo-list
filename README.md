
# To-Do List Application

## Purpose

A simple web-based To-Do List application developed using HTML, CSS, and JavaScript. The application allows users to create, view, and delete tasks, with data persistence through the browser's localStorage.

## Completed Work

- Developed the application interface using HTML and CSS.
- Implemented task creation and deletion using JavaScript.
- Added localStorage persistence to retain tasks after page refresh.
- Implemented basic input validation to prevent empty tasks.
- Created a responsive layout using CSS Flexbox.

## Testing and Evidence

### Testing Checklist

- Tasks can be added successfully.
- Individual tasks can be deleted.
- Tasks remain after refreshing the page.
- Empty tasks cannot be submitted.
- Layout displays correctly on desktop and mobile.
